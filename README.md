# Ghost Trials Autopsy

A deep research agent that investigates clinical trials that stopped early. For a drug, sponsor, condition or trial ID, it answers:

1. Why did the trial stop?
2. Were the results ever reported?
3. What did the sponsor tell investors?
4. Do those stories match?

Built for health reporters, patient advocates, and research-integrity people.

Data sources: ClinicalTrials.gov, openFDA Drugs@FDA, SEC EDGAR, PubMed, Europe PMC.
